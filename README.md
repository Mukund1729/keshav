## 🌟 Executive Overview & Platform Vision

**Ayunexis Private Limited** bridges ancient Ayurvedic wisdom (*Charaka & Sushruta Samhita* frameworks) with modern biomedical informatics, cloud-native telehealth pipelines, and data-driven preventive healthcare. 

Unlike traditional Ayurvedic portals, Ayunexis is engineered as an **institutional-grade health-tech ecosystem** that satisfies the rigorous due-diligence standards of medical boards, enterprise HR leaders, educational councils, and venture investors.

## 🚀 Advanced Tech Stack & Architectural Highlights (SDE Resume Blueprint)

Designed with modern enterprise software engineering principles, this platform showcases full-stack frontend architecture, real-time data visualization, custom state engines, and domain-driven design:

### 1. **Core Framework & Runtime**
* **React 19 + TypeScript (Strict Mode):** Enterprise-grade type safety with zero `any` evasions.
* **Vite Build Engine:** Sub-second HMR and optimized production bundling (`dist/assets`).
* **Modular Vanilla CSS Design System:** Custom CSS custom properties (`--emerald-700`, `--gold-500`, `--forest-deep`), fluid typography, glassmorphism (`backdrop-filter: blur`), and zero external utility bloat.

### 2. **State Architecture & Reactive Engine**
* **Custom Reactive Event-Driven Store (`StoreManager`):** Lightweight Zustand-like pub-sub architecture with `localStorage` persistence.
* **Multi-Tenant Role Simulation Engine:** Interactive top bar allowing instant switching between:
  * 🌐 `Visitor / Public View`: Institutional discovery & service catalogs
  * 👤 `Patient Portal`: Appointments, Prakriti profiles, and telehealth entry
  * 🩺 `Doctor Workspace`: Live patient queue, availability toggles, and e-prescriptions
  * ⚙️ `Admin CMS Studio`: Live editable impact metrics, doctor approvals, and pricing control

### 3. **Graphics & Data Visualizations**
* **HTML5 2D Canvas Force Graph (`EcosystemCanvas`):** Physics-based particle simulation rendering real-time telemetry links between Ayunexis Core, Individuals, Doctors, Institutions, and Technology.
* **Interactive AI Spectral Scanner (`AyurTaila Analyzer™`):** Real-time canvas spectrophotometry & chromatographic peak detector inspecting herbal formulations with confidence scoring and research disclaimers.
* **Dynamic Bio-Rhythm Waveform:** Canvas rendering of Vata, Pitta, and Kapha harmonic velocity.

### 4. **Telehealth & Clinical Workflows**
* **Encrypted WebRTC Telehealth Room (`TelehealthRoomModal`):** Simulated HD video consultation with live session timer, in-call clinical chat, and digital Ayurvedic e-prescription pad (PDF download ready).
* **End-to-End Doctor Booking Engine (`BookingModal`):** Multi-step wizard with slot selection, OTP phone verification simulation, Google Single Sign-On, and Razorpay test payment gateway integration with confetti celebration.
* **Prakriti Parikshan™ Assessment Engine (`PrakritiModal`):** 5-dimensional constitutional diagnostic calculating Vata/Pitta/Kapha vector scores, primary dosha classification, and personalized Dinacharya regimens.

## 🛠️ Local Setup & Building Instructions

### Prerequisites
* Node.js `v18.0.0+` (tested on Node v22.18.0)
* npm `v9.0.0+` (tested on npm 10.9.3)

### Installation
```bash
# Clone or navigate to the project directory
cd keshav

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build & Type Verification
```bash
# Perform TypeScript type-check and Vite production build
npm run build
```
